## Estrutura

```
index.html          página única com navegação fluida (âncoras)
css/style.css       estilos (mobile first)
js/config.js        chave da automação, PIN do admin, chave do storage
js/projects.js      dados da galeria de projetos
js/storage.js       CRUD em LocalStorage (JSON) + seed de 20 registros
js/app.js           galeria, navegação e formulário de contato
js/admin.js         painel administrativo oculto
assets/img/         foto e screenshots
assets/Certificado/  Certificados dos cursos feitos 
```
## Como rodar
Abra `index.html` no navegador.
